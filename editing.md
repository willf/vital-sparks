# Editing

## Style Guide

See [Style Guide](style-guide.md.)

## Process

Author:

1. Create a separate git branch.
2. Adds a draft to this branch

Editor:

1. Creates a new branch
2. Edits the the draft and pushes results
3. Creates a Pull Request with the Author's branch as base
4. Adds "Author queries" as comments on the Pull Request

Author:

1. Accepts/requests suggestions
2. Merges into author's branch and into main
